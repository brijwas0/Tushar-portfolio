# Tushar Sharma | Developer Portfolio

Personal portfolio of Tushar Sharma, a BCA student from Vrindavan, India, built for the AWS Student Builder Challenge: Build Your Tech Superpower.

**Live site:** [your Amplify URL]

## Creative feature: Discover My Tech Superpower
An interactive scan that reads my project list step by step, then reveals my interests in AI, software development, problem-solving and entrepreneurship, with my projects shown as evidence. The counts come from the real project data in the page, so nothing is invented.

## What's inside
- About, Skills and Projects sections
- Projects clearly labelled "In development" or "Concept"
- Responsive layout for mobile, tablet and desktop
- Accessible navigation, readable text and reduced-motion support
- No fake testimonials, statistics or certifications

## Tech stack
HTML, CSS and JavaScript only, with no frameworks or build step. The images and logos are embedded in one self-contained `index.html`.

## AWS
- **AWS Amplify Hosting** serves the site over HTTPS and redeploys automatically on every push to this repo.
- S3, Lambda and API Gateway are not used, because the site is static and has no backend feature.

## Run locally
Open `index.html` in a browser.

## Deploy
Connect this repo to AWS Amplify Hosting. The `amplify.yml` file needs no build step.
